# GT 方法修订：三分之二支持与一致性排序

用户于本次对话明确选择“重新设计 GT 构建规则，并同步修改论文方法”。旧实验反弹来自算法规则与描述符重叠，未发现通过改绘图或修正分母即可消除的错误。本文件记录新方法定义，不包含新版本实验结果。

新实现版本：`ground-truth-supermajority-v2`。旧实现版本：`ground-truth-reliability-v1`。Dataset、真实标签、候选采样、失败状态、阈值区间 [0.997,1]、K/M/ΔK 与重复网格不改。

## 新规则与代价

1. 候选 admission 从严格半数改为固定三分之二：θ_K=⌈2K/3⌉。K=50、75、100 的门槛分别为 34、50、67。不可用候选保留在 K 中；同伴支持排除自身，候选自身可用时计一次自支持。
2. 只从满足门槛的候选选 GT，排序为历史异常状态升序、有效同伴支持数降序、有效支持同伴平均 cosine 降序、临时 ID 升序。平均 cosine 只在支持同伴上计算，排除自身；无支持记为 −1。
3. 首次形成 M=25 即停止；不足则 50→75→100 扩展并重新核验。Fixed-K 同样使用新门槛和排序，只禁用扩展。Top-M 与 Random-M 仍为原来的无多数过滤对照。

三分之二是明确保守的协议选择，不能称为从当前成功率数据寻优得到的参数。其作用是增加接纳所需的一致支持并在相同历史下优先选共识更强的候选；代价是在候选污染与失败较高时更容易无法形成 GT。它不是 TMC 的委员会加权投票规则；没有设备信誉公式或加权票。

这个新规则仍不能在任意描述符重叠 / 故障分布下保证标签纯净，也不能保证可靠成功率曲线单调。若损坏描述符与正常实例完全不可区分，任何仅看这些观测的选择规则均无法给出一般性的真实标签保证。不得用固定输出、删除 seed、曲线平滑或强制单调替代重新实验。

## 可替换稿件 Section IV-A 的内容

### Collaborative Ground-Truth Determination

由于同一 $(p,f)$ 内的正常模型实例允许存在合法部署差异，因此无法直接指定某个 bit-identical model instance 作为统一参考。本文从当前验证域中选取历史状态较为可靠的候选实例，并通过候选模型之间的协同比较构建 $\mathcal G_{p,f}(t)$。为避免仅凭接近半数的支持接纳不稳定参考，本文采用固定三分之二支持门槛，并在历史状态相同的候选中优先选择获得更强相似一致支持的实例。该规则提高参考接纳要求，同时允许在支持不足时返回不可用状态，而不保证所有候选污染或响应失败条件下均可形成 Ground-Truth。

对于模型实例 $m_i^{(p,f)}$，记 $h_i(t)\in[0,1]$ 为其在轮次 $t$ 开始时的历史异常状态，其中较大的 $h_i(t)$ 表示历史验证过程中具有更强的异常信号。对于尚无历史记录的模型，初始化 $h_i(t)=h_0$，其中 $h_0\in(0,1)$。其具体更新规则将在 Section IV-D 中给出。设 $K$ 和 $M$ 分别为当前候选集合规模和最终 Ground-Truth 规模，且 $M\leq K$。系统按照 $h_i(t)$ 从小到大的顺序，从 $\Omega_{p,f}(t)$ 中选取 $K$ 个模型实例组成候选集合 $\mathcal C_{p,f}(t)$；历史评分相同的候选使用事先确定且与真实模型状态无关的临时 ID 顺序处理平局。候选扩展保留已有成员并从同一顺序中加入新实例。

对于任意 $m_i,m_j\in\mathcal C_{p,f}(t)$，计算候选描述符之间的相似度

$s_{ij}(t)=\operatorname{sim}(\mathbf q_i^{(p,f)},\mathbf q_j^{(p,f)})=\frac{(\mathbf q_i^{(p,f)})^{\top}\mathbf q_j^{(p,f)}}{\|\mathbf q_i^{(p,f)}\|_2\|\mathbf q_j^{(p,f)}\|_2}. $

令 $a_i(t)\in\{0,1\}$ 表示候选在当前 Ground-Truth 交互中能否正常响应。只有两个候选均具有有效描述符时，其比较才可能产生支持。对于允许合法部署差异的相似度区间 $[\tau_{p,f}^{-},\tau_{p,f}^{+}]$，定义有效支持同伴集合

$\mathcal N_i^{\mathrm{sup}}(t)=\{m_j\in\mathcal C_{p,f}(t)\setminus\{m_i\}:a_i(t)=a_j(t)=1,\ s_{ij}(t)\in[\tau_{p,f}^{-},\tau_{p,f}^{+}]\},\qquad n_i^{\mathrm{sup}}(t)=|\mathcal N_i^{\mathrm{sup}}(t)|. $

timeout 或 invalid response 不产生同伴支持；不可用候选仍占据当前 $K$ 中的一个位置，不能计入自支持或进入 Ground-Truth。设固定支持比例为 $\gamma_{\mathrm{GT}}=2/3$，并令

$\theta_K=\lceil\gamma_{\mathrm{GT}}K\rceil=\lceil2K/3\rceil. $

临时 Ground-Truth 集合定义为

$\widetilde{\mathcal G}_{p,f}(t)=\{m_i\in\mathcal C_{p,f}(t):a_i(t)=1,\ n_i^{\mathrm{sup}}(t)+1\geq\theta_K\}. $

其中 $+1$ 只表示可用候选自身的一次支持。该门槛采用高于 $1/2$ 的固定支持比例；它是固定协议参数，不随真实损坏标签、失败率或实验结果调整。

对于获得有效同伴支持的候选，进一步定义支持相似度均值

$\bar s_i^{\mathrm{sup}}(t)=\frac{1}{n_i^{\mathrm{sup}}(t)}\sum_{m_j\in\mathcal N_i^{\mathrm{sup}}(t)}s_{ij}(t), $

当 $n_i^{\mathrm{sup}}(t)=0$ 时，令 $\bar s_i^{\mathrm{sup}}(t)=-1$ 以得到确定的排序。若 $|\widetilde{\mathcal G}_{p,f}(t)|\geq M$，则按词典序键

$(h_i(t),-n_i^{\mathrm{sup}}(t),-\bar s_i^{\mathrm{sup}}(t),\operatorname{id}_i(t)) $

排序，并选择前 $M$ 个实例组成 $\mathcal G_{p,f}(t)$。历史异常状态仍是第一优先级；历史相同时，更多支持和更高支持相似度优先，最后由与真实标签无关的临时 ID 决定平局。相似度均值仅用于已经通过门槛的候选排序，不替代 admission 条件。

若当前临时集合不足 $M$，则逐步扩大 $K$，按新的候选集合重新计算支持数、门槛和排序，直至首次获得 $M$ 个参考实例或候选集合已覆盖当前验证域。若仍无法形成 $\mathcal G_{p,f}(t)$，则当前 $(p,f)$ 的验证过程延后至后续轮次；不使用未通过门槛的候选补齐。候选响应状态在同一次 GT 构建中保持不变。真实标签、数据生成原型以及来源样本 ID 均不参与候选 admission 或最终选择。

## 可替换稿件定理 1 与证明的内容

**定理 1.** 固定一次规模为 $K$ 的候选验证。令 $\theta_K=\lceil2K/3\rceil$。若保持合法模型状态且能够正常响应的候选集合 $\mathcal C^{\mathrm{nor}}$ 中任意两实例均满足相似度区间，并且 $|\mathcal C^{\mathrm{nor}}|\geq\max\{\theta_K,M\}$，则所有 $m_i\in\mathcal C^{\mathrm{nor}}$ 均通过支持门槛。对于与任意正常可响应候选均不产生区间内支持的可检测异常集合 $\mathcal C^{\mathrm{abn}}$，任意 $m_b\in\mathcal C^{\mathrm{abn}}$ 均无法通过门槛。因此，可形成规模为 $M$ 的 Ground-Truth，且 $\mathcal G\cap\mathcal C^{\mathrm{abn}}=\emptyset$。若所有损坏候选均属于该可检测异常集合，则最终 Ground-Truth 全部正常；否则该结论只排除可检测异常，不能自动推广为对所有真实损坏标签的纯净性保证。

**证明.** 对于任意 $m_i\in\mathcal C^{\mathrm{nor}}$，其余正常可响应候选均提供有效支持，且自身可用。因此

$n_i^{\mathrm{sup}}+1\geq|\mathcal C^{\mathrm{nor}}|\geq\theta_K. $

对于任意可检测异常 $m_b$，正常候选均不向其提供支持。若其不可用则直接不能进入临时集合；若其可用，则其最多只能从正常集合以外的候选及自身获得支持，从而

$n_b^{\mathrm{sup}}+1\leq K-|\mathcal C^{\mathrm{nor}}|\leq K-\theta_K<\theta_K, $

其中最后一个不等式由 $\theta_K>K/2$ 得到。因此正常可响应候选均进入临时集合，可检测异常均被排除。又因正常可响应候选数量至少为 $M$，最终排序只从临时集合选出 $M$ 个实例，故上述排除性质不因一致性排序改变。若所有损坏实例均可检测，则选出的实例全部正常；若存在与正常候选相似的轻度异常，则不能从上述前提推出对其真实标签的排除。证毕。

三分之二门槛对应可响应正常一致候选至少达到 $\theta_K$ 的充分条件，其安全余量伴随更保守的可形成性。例如 K=100 时至少需要 67 个满足上述相似度条件的正常可响应候选；该理论不能直接保证 q_C=50% 的场景可靠成功。

## 复杂度补充

候选之间仍至多执行 $K(K-1)$ 个有向 peer 相似度比较，每次复杂度为 $O(d_{p,f})$。支持数和支持相似度均值在同一矩阵上累计，额外开销为 $O(K^2)$；admitted 候选的词典序排序为 $O(K\log K)$。因此每个候选规模的总复杂度为 $O(K^2d_{p,f}+K\log K)$，主导项仍为 $O(K^2d_{p,f})$，扩展时对实际访问的各个 $K$ 累加。
